# AI-Based Green Campus E-Waste Management — Universitas Bandar Lampung

Aplikasi web interaktif pengelolaan limbah elektronik (E-Waste) kampus **Universitas Bandar Lampung (UBL)** dengan fitur pelaporan, simulasi klasifikasi AI, penjadwalan armada EV kampus, pelacakan status 4 tahap, analitik lingkungan, dan tampilan responsif desktop maupun mobile (dengan tab bar).

## Struktur Proyek

```text
├── index.html
├── package.json
├── server.js
├── assets/
│   ├── logo-ubl.png
│   ├── hero-campus.svg
│   └── eco-robot.png
├── css/
│   └── styles.css
├── js/
│   ├── data.js
│   └── app.js
└── components/
    ├── dashboard.js
    ├── lapor.js
    ├── klasifikasi.js
    ├── penjemputan.js
    ├── pelacakan.js
    ├── dashboard analitic.js
    └── pengaturan.js
```

## Cara Menjalankan Lokal

```bash
npm run dev
```

Lalu buka `http://localhost:3000` di browser Anda.
